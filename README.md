# Day 35 — Regex Validator Tool

**120 Days of Code** | NIT Rourkela | Mechanical Engineering

## What this is
An interactive regex validator tool that lets you test
regular expressions live with match highlighting.

## How to view
Open `index.html` in your browser.

## Features
- Live regex matching as you type
- Match highlighting in text
- 20+ built-in common patterns
- Match count and groups display
- Regex cheat sheet built in
